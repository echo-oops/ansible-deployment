# План демонстрации проекта "Ansible Deployment"

Этот документ — пошаговый сценарий демонстрации проекта преподавателю/комиссии. Цель — показать работоспособность, идемпотентность и тестируемость.

## Подготовка к демонстрации (что подготовить заранее)
1. Репозиторий на GitHub с веткой `main` и примером `staging` inventory.
2. Локальная машина или VM с доступом к тестовым хостам (или использовать Molecule/Docker для демонстрации ролей).
3. Убедиться, что в `group_vars/all.yml` и `inventory/staging.yml` указаны корректные тестовые хосты.
4. CI workflow (GitHub Actions) настроен и имеет хотя бы один успешный прогон (lint/molecule).
5. Подготовить скриншоты/логи:
   - Вывод `ansible-playbook` (успешный run).
   - Результат `molecule test`.
   - Логи CI run.

## Сценарий демонстрации (порядок действий)
1. **Вступление (1–2 минуты)**
   - Кратко объяснить цель проекта и используемые технологии: Ansible, Molecule, GitHub Actions, Ansible Vault.
   - Показать структуру репозитория (корневая структура и папки playbooks/ roles/ inventory/).

2. **Показ inventory и переменных (1–2 минуты)**
   - Открыть `inventory/staging.yml`.
   - Показать `group_vars/all.yml` (без секретов) и объяснить, где хранятся параметры окружения.

3. **Показ одной роли (3–5 минут)**
   - Открыть `roles/application/tasks/main.yml` и `roles/application/templates/`.
   - Объяснить, какие задачи выполняет роль (клонирование, установка зависимостей, systemd unit).
   - Показать `defaults/main.yml` и входные переменные роли.

4. **Запуск playbook'а (5–7 минут)**
   - Выполнить:
     ```
     ansible-playbook -i inventory/staging.yml playbooks/site.yml
     ```
   - Показать вывод: успешные задачи, handlers, запущенные сервисы.
   - Пояснить, какие шаги выполняются (setup → deploy).

5. **Проверка результата (2–3 минуты)**
   - Выполнить curl к приложению (например, `curl http://staging-web1:8080/health`) и показать ответ.
   - Показать `systemctl status myapp` на хосте (через Ansible ad-hoc или Testinfra).

6. **Идемпотентность (2–3 минуты)**
   - Повторно запустить тот же playbook:
     ```
     ansible-playbook -i inventory/staging.yml playbooks/site.yml
     ```
   - Показать, что изменений нет (0 changed) — объяснить, почему это важно.

7. **Тестирование ролей (3–5 минут)**
   - Запустить `molecule test` для роли `application` (или показать результат из CI).
   - Показать, что сценарий create → converge → verify → destroy прошёл успешно.
   - Показать примеры Testinfra проверок (service up, порт слушает, файл конфигурации на месте).

8. **CI/CD демонстрация (3–5 минут)**
   - Открыть GitHub Actions workflow.
   - Показать успешный run: lint → syntax → molecule.
   - Объяснить, как настроены секреты (ANSIBLE_VAULT_PASSWORD, SSH key) и почему они защищены.

9. **Вопросы и ответы (5–10 минут)**
   - Ответить на вопросы комиссии по архитектуре, безопасности, масштабируемости и дальнейшему развитию.

## Что показать в отчёте/презентации
- Скриншоты:
  - Структура репозитория.
  - Вывод `ansible-playbook` (первый и второй запуск).
  - Результат `molecule test`.
  - CI run (GitHub Actions).
- Логи:
  - Консольный вывод playbook'а.
  - Testinfra assertions.
- Краткий чеклист:
  - Inventory корректен.
  - Роли имеют defaults/vars/templates.
  - Playbook идемпотентен.
  - Тесты проходят.

## Рекомендации для демонстрации
- Демонстрируй на staging, а не на production.
- Подготовь заранее ответы на вопросы о безопасности (где хранятся секреты, как ограничен доступ).
- Если демонстрация в офлайн-режиме — подготовь заранее скриншоты и логи, чтобы показать результаты.
- Держи под рукой команды для быстрого показа состояния сервисов через Ansible ad-hoc:
ansible -i inventory/staging.yml web -m shell -a 'systemctl status nginx'
ansible -i inventory/staging.yml app -m uri -a 'url=http://localhost:8080/health status_code=200'


## Заключение
Демонстрация должна показать:
- Понимание архитектуры и структуры проекта.
- Рабочий пример автоматического развертывания приложения.
- Идемпотентность и тестируемость ролей.
- Наличие CI, который проверяет качество кода и тесты перед деплоем.
